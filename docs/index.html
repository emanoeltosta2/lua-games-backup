Lua Games Backup

Plugin de código aberto para o Millennium que salva e restaura arquivos adicionados pelo LuaTools.

Como funciona

O plugin cria um backup dos arquivos Lua e apenas dos manifestos Steam citados por eles. Quando o usuário conecta uma Conta Google, o backup é enviado diretamente para a pasta privada de dados do próprio aplicativo no Google Drive.

O aplicativo solicita somente a permissão drive.appdata. Ele não lê arquivos, fotos ou documentos existentes em “Meu Drive”. Não há servidor intermediário, telemetria nem coleta de senhas.
