Política de Privacidade

Última atualização: 10 de setembro de 2026.

Lua Games Backup é um plugin de código aberto para o Millennium que permite ao usuário salvar e restaurar arquivos do LuaTools no próprio Google Drive.

Dados acessados

O plugin solicita somente o escopo drive.appdata. Ele pode criar, ler, atualizar e excluir exclusivamente dados privados criados pelo próprio Lua Games Backup. Ele não pode ler documentos, fotos ou outros arquivos existentes em “Meu Drive”.

Os dados armazenados são arquivos Lua do LuaTools e manifestos Steam explicitamente referenciados por esses arquivos.

Armazenamento e compartilhamento

Os backups são enviados diretamente do computador do usuário para sua conta Google. O desenvolvedor não mantém servidor intermediário, banco de dados, telemetria ou anúncios, nem recebe cópias dos arquivos ou tokens.

A autorização do Google fica apenas no computador do usuário e é protegida pelo Windows. Nenhum dado é vendido ou compartilhado com terceiros. O uso das informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

Retenção e exclusão

O plugin mantém somente o backup completo mais recente. O usuário pode revogar o acesso nas permissões da Conta Google e remover os dados privados do aplicativo nas configurações do Google Drive.
